# Ftt-project

## Forex Trader Telugu (FTT)
Official web platform and community portal for **Forex Trader Telugu** by Chaitanya. Built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion.

### Features
- Responsive landing page with Hero, Meet Your Mentor, Community Overview, Structured Approach Method, Membership & Pricing, The Route, Verified Prop Firm Payouts, and Community Join sections.
- Lenis smooth scrolling with scroll-spy navigation.
- Real prop firm payout certificates with verification dialog.
- Maximum Web SEO with structured JSON-LD schemas targeting Telugu traders.

### Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
